# Checks that fail today. run.sh treats a listed failure as non-fatal and an
# unlisted one as fatal -- and it also fails when a *listed* check starts
# passing, so a fix cannot leave its entry behind.
#
# Nothing here is a gap in the native backend's coverage. Each line is a
# semantic that Core does not carry, so a consumer invented its own answer.
# These corpora were added on 2026-07-25 precisely because the harness had
# been admitting only programs both backends already agreed on, which is how
# four wrong answers stayed invisible.

# --- equality -------------------------------------------------------------
# Closed by the structural expander (semantics-closure-design.md 3): lowering
# spells the comparison out over the type's own structure, so both backends
# compile one definition instead of inventing one each. eq_adt:native,
# eq_adt:diff and eq_bytes:jvm were deleted here.

# bytes_* has no native implementation yet, so the Bytes corpus cannot reach
# the C compiler. An honest gap, not an invented answer.
eq_bytes:emitc

# --- rendering ------------------------------------------------------------
# Show is not a trait: an AdtI flag, a checker predicate, and an instanceof
# chain in dawn/rt/Show. A tagged union has no chain to walk, so there is
# nothing for native to inherit -- `to_string` of an ADT reaches emitc and
# panics.
show_derive:emitc

# A bound whose subject *contains* a rigid variable rather than being one
# (`[T: Eq]` used at `Option[T]`). Lowering's structural expander only spells
# out ground types; for anything else it falls back to the `struct_eq`
# intrinsic, which is runtime structural comparison. The JVM has one
# (Object.equals, and an `impl Eq` takes over the class's equals, so the
# recursion honours it); native has no such thing, and needs RTTI to get one.
# So this is not a missing translation -- it is a semantic the JVM gets for
# free from its object model and Core does not carry.
#
# Closed by giving the whole a dictionary built from the parts' dictionaries
# (trait-v2-design.md 3.8) rather than a runtime walk.
eq_generic:emitc

# --- dictionaries ---------------------------------------------------------
# Closed by making the table the only answer to "which dictionary is this"
# (semantics-closure-design.md 5): lowering gives every slot a real function
# to name -- synthesising one where neither an impl nor a trait default
# supplies it -- and both backends build their dictionary from that table.
# dict_forward:cc was deleted here.

# --- comptime -------------------------------------------------------------
# interp.dawn renders every non-scalar as the literal "<value>", so a const
# holding `to_string` of an ADT folds to the wrong string -- on the JVM, in
# the backend that ships. This is the check .expect exists for: both targets
# fold at compile time, so they agree with each other, and a differential
# comparison alone reports ok.
const_fold:jvm

# Comptime consts are not emitted for native yet. Unlike the four above, this
# one is an honest gap rather than an invented answer; it is listed so the
# corpus can carry the const_fold:jvm evidence.
const_fold:emitc
