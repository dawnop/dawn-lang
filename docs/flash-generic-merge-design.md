# FlashAttention 泛型主体合并

> 状态：**current**（2026-10-23；实现采用的合并约束）。依据 2026-10-23 的泛型合并任务与研究，基线为 A2 已合入的 `5c1bf13f`。

当前两个具体函数分别实现 f64 输入/累加/输出和 bf16 输入、f32 累加/输出。合并目标是一份 `[D: FloatDtype, A: FloatDtype + ScalarDtype]` 在线 softmax 主体、一份五参闭包工厂及类型化录制组装。宿主记录保存 A 类型零与负无穷，以及固定的指数、FTZ、除法和初始化选择。仅允许 Float/Float 与 BF16/F32 实例；换底后的 scale 仍由启动侧提供。

| 策略 | Float/Float | BF16/F32 |
|---|---|---|
| Q/K/V；m/l/acc/scale/O | f64；f64 | bf16；f32 |
| acc 初值 | `zeros(o)` | A 类型零的 `full` |
| 启动 scale | 运行期 `1/sqrt(d)` | 运行期 `f32(log2(e)/sqrt(d))` |
| p、alpha | exp，非 FTZ | exp2，两处 FTZ |
| l 的 reduce_sum | 原始 p | 原始 F32 p |
| 第二 MMA 的 p | 同型 `to`，零指令 | F32→BF16，最近偶数 |
| 最终除法 | 最近偶数，非 FTZ | approx、FTZ |
| 输出 | 直接存 f64 | 直接存 f32，无末端 cast |

类型化录制 helper 在发出 trace 之前拒绝其它格式对、策略字段或常量；不从 FloatDtype 推导任意 MMA 组合。宿主 Bool 分支只选择固定实例；换底 scale 属于启动侧契约。保留配置字面表、证据键和过滤规则。共享体中的普通 Bool if 在录制时只执行选中臂，未生成设备 If、策略参数或两臂 select。

首个探针同时验证现有泛型、同型宿主分支和当前 dawnc 调用图。保留声明/更新顺序、配置表、token、五参 ABI、布局与舍入；目标是六对既有 MLIR/tilebc 逐字节不变。调用图只识别经验证的固定实例选择，不展开未知宿主控制流；未选分支不得认领 IR，同型 `to` 保留零指令调用来源。先证明错臂、错 span、漏调用和未知条件会被拒绝。
