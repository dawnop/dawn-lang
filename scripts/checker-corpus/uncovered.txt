  "`dbg` cannot be used in std"	fires only while std itself is checked, and a corpus case is a user program. `check/checker`'s "dbg is the program's own" test checks a module with `is_std_module` set instead, and scripts/check-no-dbg.py keeps `dbg` out of std/ before the compiler would see it.
  "this declaration binds more than " ++ to_string(identity.slot_span()) ++ " names"	needs one declaration to bind more than `identity.slot_span()` names, which is a source file no corpus case can carry. `check/identity`'s "identity packs a binding into its declaration and its slot" test asks `pack` directly instead, and `incremental-semantics-contract/identity.py`'s pack-truncates-the-slot mutant is the control.
  "the derived identity of " ++ minted_show(decl) ++ " collides with " ++ minted_show(other)	needs two declarations whose 47-bit digests agree, which no source file can be written to produce. `check/cx.dawn`'s "two declarations that derive one id" test plants the table state instead, and `incremental-semantics-contract/identity.py`'s intern-collision-ignored mutant is the control.
