# 类型替换的恒等属性

已实现；完整配对显示局部延迟与分配收益，b sync p90 仍越线。

Capture/Scope 替换会重建不受任何替换环境影响的类型和签名。既有模块步骤复用
范围不变，这些复制发生于冷检查之内。环境结果缓存与逐层递归预扫描此前均未
取得稳定收益，本次不延续这两种方案。

唯一类型表示的复合节点和签名增加不可变布尔属性。构造时只读取直接子节点的
属性，并检查当前节点的 Scope/Capture 轴、函数 binder、effect 与签名约束。
这只是任意环境下替换恒等的充分条件；不能证明时仍执行完整替换。叶节点直接
回答，复合节点读取属性，不在替换入口重新扫描后代。所有构造和 record 更新
入口同时迁移，避免保留旧表示或兼容入口。

属性不引用环境、ADT 声明表或历史结果；不可从旧节点向修改后的节点复制证明。
opaque envelope、诊断名字、新鲜身份、支持前提与所有原有字段照常保留。量化
箭头、buffer、关联类型和显式捕获包装保守执行替换。语义相等与哈希须保持原有
字段的含义，不能让派生属性成为用户语义。

原有冻结源码的 1324 个 selfhost 测试与本分支的 1328 个测试均通过。新增契约覆盖
深度 2048 的构造、nominal 双轴、opaque 元数据、箭头 binder、签名更新与派生属性
不参与语言相等和哈希。直接对照完整替换实现，3090 次类型替换与 3315 次签名替换
通过，覆盖五种环境、三轮重复和深度 1024。两个版本对相同源码的 checker dump、
120 个 Capture 诊断用例和 11 个 emit 目标逐字节相同；run 差分及 247 条规范化
LSP 消息差分通过。自举 A、B、C 逐字节相同。

## 不做的（理由）

不清理函数或测试边界状态，该方向需要单独裁决。不增加环境缓存、投影缓存、
函数体复用，也不修改模块依赖规则、JVM 参数、采样流程或性能门槛。本方案没有
新增语法或用户接口，不能声称已经消除历史全部延迟或 RSS 回归。
