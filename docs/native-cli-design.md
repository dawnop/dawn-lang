# 原生命令行入口合同

> 状态：**current** —— 原生命令行入口、参数边界与 JVM 能力拒绝的现行合同。

安装后的命令名为 `dawn`，直接运行原生驱动本体。版本行保留
`dawnc <version> (native) b1:<digest>`，用于标识实际制品。
仓库的自举入口保持独立；需要 JVM 能力时，显式调用
`java -jar /path/to/dawn-selfhost.jar <command> ...`。

驱动在加载工程或标准库之前检查命令行。公开命令在各自的选项区域内接受
`--help` 与 `-h`，向标准输出（`stdout`）打印该命令的完整帮助条目，并返回退出码 0。
带值选项消费下一个参数，即使该参数看起来像帮助标志，也仍将其视为值。
`run` 在目标处停止解析编译器选项，原样传递 `--` 后的程序参数。

未知命令、未知选项、选项缺值及不支持的 JVM 能力均返回退出码 2，错误信息只写入
标准错误（`stderr`），标准输出为空。其中，`--cp` 被直接拒绝，不检查其路径，也不校验后丢弃。
LSP 的帮助请求在启动服务器之前返回；除帮助请求外，LSP 仅接受 `--std <dir>`。

内联测试通过捕获控制台与退出效果来验证参数边界。原生命令行差分保留可移植命令的
双后端对拍，并用独立的完整文本预期检查公共帮助。外部探针用 FIFO 阻塞真正的
标准库读取，记录工具启动尝试，并在请求 LSP 帮助时保持标准输入（`stdin`）打开。
所有探针复用传入的原生二进制。
