# Every check label the four differential gates print, and the only strings an
# `Emit-Change(...)` declaration may name (scripts/emitchange.sh).
#
# This file is not a hand-kept copy of the scripts. Every differential calls
# `emit_gate` for every check it runs -- passing or failing -- and `emit_gate`
# fails when the label it is handed is missing from here. Adding or renaming a
# label without editing this file therefore reds the same gate that reads it,
# in the same run, printing the exact line to add. That is what makes "unknown
# label" always mean the declaration is wrong and never that this file is
# stale.
#
# Labels are compared literally (grep -Fx). Blank lines and lines starting
# with `#` are comments.
#
# selfhost-core-diff.sh is deliberately absent: Core drift is re-recorded with
# `--record` into scripts/core-golden/, never declared. `Emit-Change(core ...)`
# has never matched anything and is now an error.
