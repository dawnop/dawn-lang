# The layer-2 ledger (docs/tile-backend-design.md 6.4): one line per run of
# scripts/tile-gpu-diff/run.sh on a machine with a driver, appended by the
# script, never by hand.
#
#   <commit> <date> <driver> <tileiras> <gpu-name> <result> [# note]
#
# result is `pass` (vadd on the GPU bit-identical to the fake device in every
# input set), `blocked:<kind>@<stage>` (the driver refused at that stage; the
# note is its message) or `fail`. `run.sh --check`, the CI gate, requires the
# last line's commit to be an ancestor of HEAD with no tile path changed since,
# and its result to be pass or blocked: what it refuses is silence.
