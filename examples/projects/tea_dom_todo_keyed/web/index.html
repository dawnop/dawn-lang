Every edit is a message. A listener declares that it wants the element's value, the bridge brings back that one string with the event, and the guest folds it into the message the listener named, so a title of any length costs one turn and pasting works. Click a row's title to edit it. Press boom to make the guest's update panic: the failure lands inside wasm, the page keeps the document it has, and the next press works.

The rows are keyed by id. Open one for editing, leave the caret in the middle of the text, then delete a row above it: the editor keeps the focus and the caret does not move, because the reconciler paired that row by its key and the bridge moved the element the document already had. examples/projects/tea_dom_todo is the same application without the keys, and is deliberately left that way.
