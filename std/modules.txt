# Bundled std modules, in dependency order (spec §10.6). Each name is a
# resource std/<name>.dawn, importable as `use std/<name>`; the file's name is
# the qualification alias (map.insert, str.trim, ...).
cursor
str
# char before fmt and bytes: both scan ASCII digits, and reading a character
# as its code point is `char.code`, so the module has to be checked first.
# Its own tests therefore stop at std/str -- the "a character can be a Map
# key" claim lives in std/map's tests, which are checked after both.
char
fmt
# narrow depends on nothing but the builtins; it sits here so the modules
# below may use it, though none does today.
narrow
# list precedes bytes: `for` desugars through the prelude Iter trait, and
# bytes' own for-loops need the `impl Iter[List[T]]` std/list registers
list
bytes
io
# The reactor pump owns a process/module-lifetime root through internal io
# runtime primitives. It depends only on io and precedes the collections.
reactor
map
set
hamt
pvec
# gpu is host-side only (the Gpu effect, typed tensors, the fake device) and
# needs list and map; nothing in std uses it.
gpu
