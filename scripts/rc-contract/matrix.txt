# Which assertions each production mutant reddens, and which one owns it.
#
# `assert` names the roster, in the order rc_test.c runs it. The red sets are
# observed by run.sh and compared with this file; the `owner` line is a hand
# edit, because which assertion owns a mutant is a design decision and a
# recorder that could reassign owners would launder the collision it exists to
# catch.
#
# Overlaps are recorded, not forbidden. `revert-adt0-to-fresh-allocation`
# reaches `none_is_shared` as well, because the runtime's own `None` goes
# through the same shared object; what may not overlap is an owner.
#
# The controls are the assertions that stand closest to the mutations and
# must survive them anyway. `array_with` is the one reader of
# `dawn_is_unique` whose answer the singleton moves, and `immortal` is the
# pre-existing dup/drop guard the singleton reuses; a mutant that reddens
# either has stopped being about field-less constructors. `counts` and
# `sharing` are the same line for the allocator: every slab mutant below is
# still a working allocator, so a mutant that cannot count or cannot share
# has broken something other than the property it is named for.

# The bound and the retirement are one mechanism, so one mutant reddens both:
# a run that never hands a slab back has no retirements to count and no bound
# holding what it keeps. This is the mutant the knife rests on. Every answer
# the program prints under it is correct and every other gate in the tree
# stays green; the only thing that changes is that the memory never comes
# back, which is the whole reason the allocator was written.
role	slab-never-retires	counted
owner	slab-never-retires	slab_returns_pages
red	slab-never-retires	slab_returns_pages
red	slab-never-retires	slab_bound_is_honoured

role	slab-swallows-oversize	counted
owner	slab-swallows-oversize	oversize_leaves_the_slab
red	slab-swallows-oversize	oversize_leaves_the_slab
# Raising DAWN_SLAB_MAX grows the class table, and the idle budget literal
# (32MiB, written in rc_test.c rather than derived) reddens with it: a slab
# cache that swallows oversize blocks has also outgrown its documented bound.
red	slab-swallows-oversize	slab_bound_is_honoured
