# The end-to-end evidence corpus: every program in scripts/spike-native/ whose
# subject is what a call site puts in an evidence slot and what the callee
# reads back out of it.
#
# One line per entry: `<name> <assertions|transcript>`.
#
#   assertions  the file carries inline `test` blocks, and they must pass.
#   transcript  the file's `main` and its .expect are the whole of it.
#
# Both kinds are replayed against their .expect on every run, so `transcript`
# is not a weaker check -- it is the statement that this entry has no assertion
# lane yet. Moving an entry from `assertions` to `transcript`, or deleting a
# line, is the edit this file exists to make visible.
#
# The roster is a ratchet in both directions. A listed entry that is gone fails
# the gate; a `scripts/spike-native/effect_*.dawn` that is not listed fails it
# too, so a new evidence corpus cannot arrive without someone saying which of
# the two lanes it is in.
#
# What each entry owns:
#
#   effect_handler          a handler answers an operation at all; the floor.
#   effect_lexical          which handler answers, when two are in scope.
#   effect_fn_value_supply  a function value's effects are answered at the
#                           call, not where the value was written.
#   effect_params           `fn`, `alias` and `type` effect binders, declared.
#   effect_decl_row         the same binders *consumed*: a declaration-typed
#                           value arriving at a signature with a variable of
#                           its own, under the `!io` the diagnostic advises
#                           (#345).
#   effect_io_absorb        `!io` standing over a variable that is still read,
#                           declared and inferred (#345).
#   effect_alias_earg       a row written as an **effect argument** at a
#                           transparent alias's type application, substituted
#                           into the expansion: a consumer's variable, a label,
#                           a union of two, a label beside a variable, io
#                           beside a variable, and two binders in order.
#   effect_var_union        a variable instantiated to a union.
#   effect_two_vars         two variables meeting in one slot: the tail is a
#                           join, not a splice.
#   effect_var_mixed        a label consed over a forwarded chain, from the
#                           callee's own row.
#   effect_widen_row        the same shape in a *parameter's* row, at an
#                           ordinary Dawn callee, and on into both primitives
#                           (#335, and #335 crossing #346).
#   effect_row_subtract     the same subtraction one axis over: the concrete
#                           atom is in the *base* union rather than a written
#                           label, so the residual has to be computed before
#                           the containment test rather than handed over by it
#                           (#350).
#   effect_pack_superset    a pack with more in it than the reader asked for.
#   effect_primitive_row    `bracket` and `sort_by` pay for their own row at
#                           the call site, use closure and release closure
#                           (#346).
#   effect_barrier_row      the same for the two io barriers, which bind `!e`
#                           over the closure they protect while their own row
#                           stays `!io` (#343).
#   assoc_effects           an associated effect through a trait.
#   trait_effect_var        an effect variable in a trait method's row.
