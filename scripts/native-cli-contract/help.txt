dawn @VERSION@, the Dawn compiler's native CLI.

usage:
  dawn check [--std <dir>] <target>...       type-check, report diagnostics
  dawn build [--std <dir>] <target> [-o out] compile to a native binary via cc
  dawn build --target wasm <target> [-o out] compile to wasm32-wasip1 via clang
  dawn build --target wasm --reactor <target> [-o out]
                                              export dawn_turn without _start
  dawn emitc [--std <dir>] <target> [-o out] emit the C translation unit
                                              --build-info <file.c>, --split <dir>,
                                              --map <file> write additional outputs
  dawn run [--std <dir>] <target> [-- <args>...]
                                              compile and run; preserve program argv
  dawn test [--std <dir>] <target>          compile test blocks via cc and run them
  dawn test [--std <dir>] --stdlib          run the bundled std's own test blocks
  dawn fmt [--check] <file.dawn | dir>...    format files in place or check formatting
  dawn doc [--std <dir>] <target> | --stdlib | --builtins
                                              emit the API reference as JSON
  dawn add <spec> [--subdir <p>] [--as <alias>] [--dir <project>]
                                              edit dependencies in dawn.toml;
                                              Maven coordinates need JVM tools later
  dawn cache verify                       check every cached package's hash
  dawn lsp [--std <dir>]                   speak LSP over stdin/stdout
  dawn parse <file.dawn>...                print the syntax tree
  dawn version                            print native version and source digest
  dawn version -m <project-dir | binary>... print project, native or wasm build manifests

A <target> is a .dawn file or a project directory (src/main.dawn entry).
--help or -h in a command's option region prints its help without loading std.
--version, -V or version prints the native artifact identity and source digest.
--comptime-fuel <n> (check/build/emitc/run/test) sets constant evaluation fuel
(default 100000000). -O0, -O1 or -O2 (build/run/test) sets cc optimization
(default -O2). Native is the default build target; wasm needs clang and WASI.
--std <dir> overrides nonempty DAWN_STD, then the embedded std is used.
The working directory is never searched for std. Package downloads need curl.
Java interop, JAR output, lock, --cp, --closure, --native and --vendor need the
explicit JVM toolchain: java -jar /path/to/dawn-selfhost.jar <command> ...
