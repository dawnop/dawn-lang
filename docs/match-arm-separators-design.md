# match 臂显式分隔设计（SYN-10）

> 状态：**current** —— 本文记录 SYN-10 的定稿契约、恢复边界与迁移结果。Dawn 尚处
> 早期，本刀有意拒绝旧的零宽臂邻接；稳定、局部可判定的分隔规则比兼容一条会随
> pattern/postfix 扩展而漂移的启发式更重要。

## 1. 问题

旧 parser 在一个臂体后没有看到换行、逗号或 `}` 时，会调用 `can_start_pattern`。只要下一
token 看起来能开始 pattern，就把它当作下一臂。因此连空格都不是必需条件，
`match x { 0 -> 1 1 -> 2 }` 也会被拆成两臂。

这条规则复制了 `pattern_p` 的 FIRST 集，而且边界同时取决于前一表达式的 postfix 集：
以 `[` 或 `(` 开头的下一 pattern 可能先被前一臂吞成 index/application。以后新增一种
pattern 或 postfix，还会追溯性改变旧源码的 parse。分隔规则不应由两份不断变化的 token
清单共同决定。

## 2. 方案比较与裁决

候选有三种：

1. 只允许物理换行；
2. 允许物理换行或 `,`；
3. 保留 token 邻接与 `can_start_pattern`。

裁为方案 2。全仓勘察的 4,693 个真实臂边界中，4,665 个已经换行，23 个已经用逗号，只有
5 个源码边界需要迁移。逗号保留紧凑 match 的用途，换行保持多臂代码的主风格；方案 3
继续维护重复 FIRST 集，方案 1 则无必要地拒绝已经清楚且无歧义的紧凑写法。

## 3. 定稿语法

- 相邻臂只能由 `NEWLINE` 或 `COMMA` 分隔；空格与零宽邻接都不是分隔符；
- `COMMA` 后可有任意个换行；
- 最后一臂后允许尾逗号；
- `RBRACE` 结束 match，`EOF` 只作为恢复终点，缺失 `}` 仍是语法错误；
- 缺分隔符固定报告下列诊断，不得因下一 token 恰好能开始 pattern 而静默拆臂：

  ```text
  expected a newline, `,` or `}` after this match arm
  ```

lexer 与 formatter 的 newline continuation 规则不变。臂体表达式内部的换行是否续接，
仍由 §1.7 与表达式 parser 决定；本刀只处理表达式已经结束后的臂边界。

## 4. 恢复边界

坏臂恢复必须从**该臂起点**重新扫描。若从最终报错 token 才开始，报错前已经消费的左括号
不可见，恢复会把嵌套换行误当下一臂。

扫描分别追踪 `()`、`[]`、`{}` 深度：

- 三种深度都为零时，`NEWLINE` / `COMMA` 才是下一臂边界；
- 未被臂内 `{` 配对的 `RBRACE` 是当前 match 的结束，立即停下，不能吞掉后续声明；
- `EOF` 无条件停止；
- 恢复不查看 FIRST(pattern)，否则只是把被删除的启发式藏进错误路径。

## 5. 迁移

真实源码只有五个零宽边界：`selfhost/src/main.dawn` 两个、
`selfhost/src/ir/lower.dawn` 三个，均改为逗号。另有
`selfhost/src/check/checker.dawn` 一段动态 parser fixture，以及中英文规范各一个示例；
它们同样补逗号。全仓其余臂已经使用换行或逗号，不改排版。

## 6. 可执行契约与负控

parser 单测与 grammar corpus 同时覆盖：

- 同行逗号、逗号后换行、尾逗号三个正例；
- 同行无逗号的相邻臂，精确钉住一条缺分隔符诊断；
- 一个同时嵌套 `()`、`[]`、`{}` 的坏臂，精确钉住单条原始诊断，并要求后续臂与声明仍被保留。

两项负控必须实际见红后恢复：

1. 临时恢复 `can_start_pattern` 邻接分支，缺分隔符 reject 会解析成功，grammar corpus 必须红；
2. 临时让恢复忽略 nesting，recovery fixture 会产生级联诊断，精确诊断序列必须红。

Core golden 与跨 release Emit 差分只按门禁实测更新或声明，不按设计预测预写。

## 7. 不做的（记录理由）

- **不改 lexer/fmt 的换行续接。** 臂分隔发生在表达式 parser 已返回之后，不应借机重定义表达式。
- **不生成共享 FIRST(pattern)。** 显式分隔后正常路径和恢复路径都不需要它；保留只会制造未来漂移点。
- **不自动插逗号。** formatter 不应替语法错误猜作者想把哪段拆成下一臂。
- **不兼容旧邻接一代。** 仓内迁移只有五个边界，兼容期会让歧义继续进入新源码。
