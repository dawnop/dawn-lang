# Checks allowed to fail, each with the finding it records. Spike-native's
# ratchet rules: an unlisted failure is fatal, and so is a listed check that
# starts passing -- fix means delete the line and upgrade the expectation.
#
# `std/pvec:index` held the intrinsic-jurisdiction finding here while the
# whole pvec surface was pinned owned (its both-flip was an LSan leak: the
# `list_index` call sites never read the table). The C emitter reads the
# callee's row at every list-primitive call site now, so `index` is an
# ordinary borrowed row and the flip is green; the entry came out the day the
# intrinsic lowering read the same table, as it said it would.
#
# What stays pinned is `list_push`'s list operand, which the primitive
# consumes by its own convention (`c/infer.list_owned_positions`). `push`'s
# body consumes it too, so the coherent flip is refused at compile time, like
# the three entries below; the probe is on the roster so that pin has a
# corpus site, not because it is a leak finding.
std/pvec:push:2:0=both

# (The other five both-flips went green when `rc_check` learned the table
# and the mode-contract assertion landed -- knife 2 step 0; the five
# known-red lines that pinned the checker gap came out then.)
std/pvec:push:2:0=both

# Three sites whose parameter the inference decided OWNED (the body
# consumes it: str.len hands s to count, whose TCO loop reassigns its
# binding; reverse and take hand xs to their _go helpers likewise). The
# `both` toggle therefore forces borrowed onto a consuming parameter, and
# the zero-new-dup contract refuses at compile time:
#
#   panic: rc: borrowed parameter ... reached a consuming position
#
# That refusal (rc.rw's borrowed-consume panic) is the machinery the demand
# rules' production mutants rely on, and these entries are its live
# exercise in CI. If a later knife relaxes the contract (Lean-style
# escape-plus-dup), these start passing and this ratchet fires.
std/str:len:1:0=both
std/list:reverse:1:0=both
std/list:take:2:0=both
