# The layer-2 ledger of the GPU cluster's B200 (sm_100), kept by
# scripts/tile-gpu-diff/run.sh --toolchain scripts/tile-golden/toolchain-sm100.txt.
# Its shape is ledger.txt's, one line per run, appended by the script and
# never by hand:
#
#   <commit> <date> <driver> <tileiras> <gpu-name> <result> [# note]
#
# WHAT THIS LEDGER IS FOR, and how it differs from ledger.txt. ledger.txt is
# this repository's own machine and the one `run.sh --check` reads, so it is
# the gate: CI refuses a tree whose tile paths moved after its last line.
# This file is read by no gate at all. What it buys is the rows that
# ledger.txt cannot buy on any tree, because the card it records cannot load
# the cubins: the four fp8 and fp4 rows of scripts/tileir-features/types.txt
# and the `mmaf_scaled` row of features.txt were `architecture` exemptions
# from knife T3 onward, and a run recorded here is what retires them.
#
# The `arch=` field of the note is what a reader of those tables follows.
# It is `ran=<kernels> skipped=<kernels>@<gpu-name>`, and
# scripts/tileir-features/check.py reads it: a row whose evidence names
# `device@sm100:<kernel>` is held to this file's last line, which must
# record `pass` and must name that kernel in its `ran=` list. A kernel in
# `skipped=` bought nothing, and saying so is the point of writing both
# lists down rather than only the one that ran.
