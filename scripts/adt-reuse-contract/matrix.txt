# Which assertions each mutant reddens, and which one owns it (the shape
# scripts/rc-view-contract/matrix.txt copies from map-reuse-contract).
#
# `emits` is red alone when the mutant compiler cannot produce C at all (the
# balance oracle refusing the program); nothing after it can be judged.
# `finished` is the sanitizers' verdict (exit status, ASan, LSan) and
# `answers` is the program's stdout against expected.txt, which was recorded
# from the compiler before any reuse existed. The four rate assertions are
# counter budgets and cannot see a wrong answer, which is why the first two
# exist.

assert	emits
assert	finished
assert	answers
assert	update_zero_alloc
assert	tree_reuse_rate
assert	list_reuse_rate
assert	ask_reuse

owner	pairing-off	update_zero_alloc
red	pairing-off	update_zero_alloc
red	pairing-off	tree_reuse_rate
red	pairing-off	list_reuse_rate
red	pairing-off	ask_reuse
