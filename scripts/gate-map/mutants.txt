# Which assertion each mutant reddens, and which one of them owns it.
#
# Regenerate the `red` lines with `gatemap.py --record-mutants`. The `owner`
# and `control` lines are a hand edit, because which assertion owns a mutant is
# a design decision and a recorder that could reassign owners would launder the
# collision it exists to catch.
#
# Overlaps are recorded, not forbidden; what may not overlap is an owner. See
# the block comment above `Check` in gatemap.py for the five rules, and
# scripts/pipe-contract/matrix.txt for the precedent this copies.
#
# As recorded today every mutant reddens exactly one assertion, so there are no
# overlaps to read. That is a fact about this tree rather than a rule: the rule
# is only that an owner is not shared, and a later mutant is free to redden
# more than one thing as long as the one it owns stays its own.
#
# Three entries are not like the others:
#
#   unwatched_floor is a `control`. Nothing here owns it and nothing may redden
#   it. It is the sentence every mutant has to keep true, and it exists because
#   the failure it describes (rule B growing an appetite until the unwatched
#   set is empty and the map says everything is covered) happened twice while
#   this directory was being written.
#
#   glob-with-a-wildcard-head is `recorded` rather than counted, and its red
#   set is deliberately empty. With the guard in resolve() present the mutant
#   changes nothing, so it can own nothing; what makes it worth having is rule
#   3, which fails the moment it starts reddening anything. Its companion
#   glob-with-a-literal-head edits the same file and is counted, so if that
#   file is ever renamed the pair does not quietly go vacuous.
#
#   package-whose-name-is-not-its-directory is the same arrangement, for the
#   same reason. A package renamed by a major bump keeps its directory, and a
#   rule C that read the name off the directory reddened on a tree that was
#   perfectly correct. A manifest-driven rule C is unmoved by it, so its red
#   set is empty and rule 3 is what holds it there.
#   package-renamed-in-its-manifest edits the same manifest and is counted.
