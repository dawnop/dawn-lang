# The H200 of the GPU cluster: the machine of scripts/tile-gpu-diff/ledger-sm90.txt.
#
# toolchain-sm100.txt's header says what a second toolchain file is, what it
# carries and why it carries no `wheel` line. This is the same thing for the
# other card, and the reason there are two rather than one is a measurement
# knife TA made: sm_90 accepts `f8E4M3FN` and `f8E5M2` and refuses
# `f8E8M0FNU` and `f4E2M1FN`, so the fp8 wall the earlier knives recorded as
# one wall is two, and this ledger is the machine that stands between them.
#
#   gpu-name   sm_90. `nvidia-smi --query-gpu=compute_cap` reports 9.0 on
#              this card, and run.sh holds the two together.
#   driver     580.95.05, as nvidia-smi reports it on the H200. The B200 of
#              the other ledger runs 580.159.04: two machines of one cluster
#              are not one machine, which is the whole reason a ledger
#              belongs to a toolchain file and not to a repository.
bytecode 13.3
tileiras 13.3.36
gpu-name sm_90
