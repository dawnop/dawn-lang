# SHA-256 of every release's dawn-selfhost.jar — the bootstrap seed.
#
# 为什么存在：种子 jar 是整条工具链的信任根。`seedjar.sh` 从 GitHub Release 下载它、
# 永久缓存、然后**永远不再校验**。首次下载被中间人替换、CDN 返回坏字节、release 资产
# 被重新上传、或者本地缓存被改写——任何一种都会换掉编译所有 Dawn 代码的那个编译器，
# 而 B==C 固定点会忠实地把它复现出来（固定点证明的是自洽，不是可信，见 BOOT-03）。
#
# 格式：`<sha256>  <tag>`。`seedjar.sh` 在每次使用前校验，不只是下载后。
#
# **这份清单的信任边界**：这些值是 2026-07-25 从 GitHub Release 重新下载得到的，
# 并与本机 `.dawn/seeds/` 缓存逐一比对一致。也就是说它把「以后拿到的种子」钉到了
# 「当时 GitHub 上的种子」——这是 trust-on-first-use，不是来源证明。它能挡住此后的
# 篡改、损坏和资产替换；它不能证明当初上传的 jar 就对应声称的源码。真正的来源证明
# 需要 release workflow 签名 + 可复现构建（BOOT-03/BOOT-04），见 docs/codebase-audit.md。
#
# v0.7.0 不在此列：那个 release 的资产叫 `dawn.jar`（Kotlin 实现），不是 selfhost 种子。
