# Checks that fail today. run.sh treats a listed failure as non-fatal and an
# unlisted one as fatal -- and it also fails when a *listed* check starts
# passing, so a fix cannot leave its entry behind.
#
# Every line left is a gap in the native backend's *coverage* -- a feature it
# does not have yet -- and none is an invented answer. That is a change: when
# these corpora were added on 2026-07-25 four of the entries were semantics
# Core did not carry, so each consumer made one up, and the harness had been
# admitting only programs both backends already agreed on, which is how those
# four stayed invisible. They are closed (each is recorded below, at the
# section it was in). What remains is bytes, collections and comptime consts,
# none of which native implements at all.

# --- equality -------------------------------------------------------------
# Closed by the structural expander (semantics-closure-design.md 3): lowering
# spells the comparison out over the type's own structure, so both backends
# compile one definition instead of inventing one each. eq_adt:native,
# eq_adt:diff and eq_bytes:jvm were deleted here.

# bytes_* has no native implementation yet, so the Bytes corpus cannot reach
# the C compiler. An honest gap, not an invented answer.
eq_bytes:emitc

# `derive Ord` was here: its body was written straight to JVM bytecode, so
# Core never carried it and the C backend emitted a *call* to
# `impl$0$Adt<n>$cmp` with no definition -- an undefined symbol and no
# diagnostic at all. No corpus covered `derive Ord` until 2026-07-26, which is
# why that stayed invisible. Closed by lowering the comparison the way the
# structural equality already was, so both backends compile one definition:
# ord_derive:cc was deleted here.

# --- rendering ------------------------------------------------------------
# show_derive:emitc was here. Show was not a trait but three things wearing
# one name -- an AdtI flag, a checker predicate, and an instanceof chain in
# dawn/rt/Show -- and a tagged union has no arm in that chain, so it fell
# through to the `toString` the JVM emitter wrote directly as bytecode. Core
# carried neither end. Closed by lowering the rendering over the type's own
# structure the way equality and ordering already are
# (semantics-closure-design.md 6), so both backends compile one definition.
#
# The container half was here for a reason that has since been replaced. It
# used to be that `show` at a List/Map/Set reached the runtime intrinsic and
# native had no runtime to reach; std carries `impl[T: Show] Show[List[T]]`
# now, so rendering goes through the same synthesised bodies show_derive.dawn
# does. The file still cannot reach the C compiler, but the wall it hits is
# `emitc: list literals await the pure-Dawn collections (D1-D3)` -- those
# landed and emitc has not been re-derived against them. That is S4's work,
# not Show's.
show_containers:emitc

# A bound whose subject *contains* a rigid variable rather than being one
# (`[T: Eq]` used at `Option[T]`) was here. It reached the `struct_eq`
# intrinsic -- a runtime structural walk the JVM has (Object.equals, which an
# `impl Eq` takes over) and native does not. Closed by building the whole's
# dictionary out of the parts' (trait-v2-design.md 3.8) instead of walking:
# eq_generic:emitc was deleted here.

# --- dictionaries ---------------------------------------------------------
# Closed by making the table the only answer to "which dictionary is this"
# (semantics-closure-design.md 5): lowering gives every slot a real function
# to name -- synthesising one where neither an impl nor a trait default
# supplies it -- and both backends build their dictionary from that table.
# dict_forward:cc was deleted here.

# --- comptime -------------------------------------------------------------
# const_fold:jvm was here. interp.dawn rendered every non-scalar as the literal
# "<value>", so a const holding `to_string` of an ADT folded to the wrong
# string -- on the JVM, in the backend that ships. This is the check .expect
# exists for: both targets fold at compile time, so they agree with each other
# and a differential comparison alone reports ok.
#
# Closed in two halves. Rendering became a Core body, so the interpreter has
# the same definition the backends compile; and the interpreter learned to
# dispatch through a dictionary, which is what a rendered container reaches
# once std carries `impl[T: Show] Show[List[T]]`. It refused before, which
# would have turned the wrong answer into a compile error rather than a right
# one.

# Comptime consts are not emitted for native yet. Unlike the four above, this
# one is an honest gap rather than an invented answer; it is listed so the
# corpus can carry the const_fold:jvm evidence.
const_fold:emitc
