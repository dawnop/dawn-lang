# Names that left std, and what to write instead. Read by the std loader
# (selfhost/src/driver/stdlib.dawn) into the checker's hint table; the format,
# the expiry rule and the gate are in docs/std-moved-design.md.
#
# One entry per line, blank-separated; `#` starts a comment anywhere, so a
# hint cannot contain one:
#
#   <scope> <old> <new> <since> <until> <hint...>
#
#   scope  `std/<module>` for a qualified call `alias.old(...)`, or `builtin`
#          for a flat spelling `old(...)`
#   old    the name that can no longer be written
#   new    the spelling to use now (`<module>.<fn>` or a builtin), or `-`
#   since  the release the name left in, X.Y.Z
#   until  the release the hint expires at, by default ten minors after since;
#          `dawn test selfhost` fails once VERSION reaches it
#   hint   the rest of the line, shown verbatim; `no-hint` records a removal
#          made on purpose with nothing to say
#
# scripts/std-moved-check/ fails when a pub fn of the previous release's std
# is gone from this one and has no line here, hint or `no-hint`.
#
# Example (expired, for the shape only):
#   std/str substring str.slice 0.55.0 0.65.0 renamed: write `str.slice(s, from, to)`
