# Scripts that find code by spelling it, and what holds each one's anchors.

# Read by scripts/anchor-guard.py (tree-policy), which fails both ways: a
# tracked script under scripts/ that names a source file and contains a text
# match must have a line here, and a line whose script is gone or no longer
# matches must go. The rule over-approximates on purpose; see that script's
# header for it and for the four kinds:
#
#   preflight   proven exactly-once by mutation-anchor-preflight.py (checked)
#   self-once   refuses a literal that does not match exactly once (checked)
#   unproven    reads source text by spelling, and nothing proves its
#               literals unique. This is the open debt of ruling 9(a).
#   not-anchor  matched by the rule, but does not locate code by a literal
#
# Each line is `<path>  <kind>: <why>`.
